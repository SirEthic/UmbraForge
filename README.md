# UmbraForge

*"Shadows are Solid Matter."*

UmbraForge is an atmospheric puzzle-platformer set within ancient bioluminescent ruins. You navigate the abyss not by moving platforms, but by bending light itself to cast physical, solid shadow bridges across the dark.

## Running the Game
1. Open Godot 4.6 (or compatible 4.x Forward Plus version).
2. Import the `UmbraForge` folder.
3. The game will automatically launch into **The Forge** (Hub World).

**Controls:**
- **A / D**: Move left and right
- **W / Space**: Jump
- **Hold Left Click**: Drag your magical Lantern Drone
- **Right Click**: Instantly recall the Lantern to your hand
- **ESC**: Quit
